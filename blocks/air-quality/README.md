# Air quality

Current US AQI as the headline number, with PM2.5 in µg/m³ underneath,
from Open-Meteo's air-quality API (keyless, same provider as the built-in
weather). Set `lat`/`lon` to your location — the wizard's geocoder shows
both for your city if you don't know them.

The value is drawn with the accent colour, so it comes out red on
tri-colour panels and black on b/w ones. Suggested size: 5x3.
