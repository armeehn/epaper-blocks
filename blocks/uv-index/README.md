# UV index

Current UV index with the WHO exposure category (Low / Moderate / High /
Very high / Extreme), from the Open-Meteo air quality API. No key; free for
non-commercial use. Set your latitude/longitude in the block parameters.
Pairs well next to the `air-quality` block. Suggested size: 4x3 or larger
(the category sub-line appears at heights of 4+ rows).
