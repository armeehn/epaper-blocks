# Hacker News

Front-page stories with their point counts, as "title / points" rows, via
the Algolia HN search API (keyless). Pick 3, 4 or 5 stories with the
`count` parameter — the engine caps extracted lists at 6 rows either way.
Long titles are truncated to the block width rather than wrapped, so wider
is better here. Suggested size: 6x3, or 8x4 to read more of each title.
